# MVP acceptance criteria

The prototype is ready for an in-room trial when all of these are true:

- [ ] Starts on a Mac with one command
- [ ] Launches Chrome in full-screen kiosk mode
- [ ] Captures clear microphone audio from the intended standing position
- [ ] Supports interruption without losing the active job
- [ ] Routes complex requests to Astra
- [ ] Displays at least three progress updates during a job
- [ ] Can open, inspect, and display a public website
- [ ] Presents a readable result at projection distance
- [ ] Blocks a private-network navigation attempt
- [ ] Requires approval for every external write action
- [ ] Recovers cleanly after API or browser failure
- [ ] Records enough events to diagnose a failed demonstration

## First live demonstration

> Astra, research three ecommerce marketing agencies, compare their positioning, and present the clearest opportunity for a new competitor.

Expected result:

1. Voice agent acknowledges the request.
2. Wall moves from listening to planning.
3. Astra opens public sources in the isolated browser.
4. Screenshots appear while the task runs.
5. Wall finishes with a concise comparison and recommendation.
